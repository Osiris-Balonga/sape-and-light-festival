# Sape and Light Festival

One-page event website for the fictional Festival Sape & Lumière in Brazzaville.

## Local development

Run the included local server from the project directory:

```powershell
node scripts/serve.mjs
```

Open `http://localhost:4173` in a browser.

## Project structure

- `index.html` contains the page structure and French visitor content.
- `assets/css/` contains design tokens, foundations, components, and responsive rules.
- `assets/js/main.js` provides navigation, countdown, tabs, filters, and form validation.
- `assets/images/` contains responsive festival and artist imagery.

## Before publishing

Replace the placeholder WhatsApp number, dates, timetable, prices, venue details, partner names, and artist names with approved event information.
